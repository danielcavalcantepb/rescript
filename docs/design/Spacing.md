# Espaçamento

---

## 1. Escala base (4px)

| Token | px | Uso |
|---|---|---|
| `space-1` | 4 | micro gap ícone-texto |
| `space-2` | 8 | compacto interno |
| `space-3` | 12 | padding controle |
| `space-4` | 16 | padrão card/padding |
| `space-5` | 20 | |
| `space-6` | 24 | seção |
| `space-8` | 32 | entre blocos |
| `space-10` | 40 | |
| `space-12` | 48 | page padding desktop |
| `space-16` | 64 | respiro hero/onboarding |

---

## 2. Princípios

- **Ritmo generoso na Central de Decisão** (calma).  
- **Tabelas e listas operacionais** mais densas (`space-3` rows) — velocidade.  
- Nunca “encostar” CTA no texto sem `space-4+`.  
- Formulários: `space-4` entre campos; grupos `space-6`.

---

## 3. Layout grid

- Conteúdo max-width app: ~1280–1440  
- Sidebar: 240 colapsável → 64 ícones  
- Gutters: 24 desktop / 16 tablet / 12 mobile  

Justificativa: Linear/Stripe usam respiro seletivo — densidade onde há scan, ar onde há decisão.
