# Gráficos

---

## 1. Posição na hierarquia

**Conclusão > número > gráfico.**  
Central de Decisão: gráficos **não** são o default.

---

## 2. Quando um gráfico é permitido

- Tendência de vendas no tempo em Visão geral **secundária** ou página de relatório leve  
- Usuário pediu “ver evolução”  

Nunca: pizza de status; 3 eixos; gauges.

---

## 3. Estilo

- Linha ou barra simples  
- 1 cor accent + gray  
- Tooltip com valor exato  
- Eixo Y com escala honesta (não cortar para dramatizar)  

---

## 4. A11y

Tabela de dados equivalente disponível; não cor só como canal.
