# Responsividade

---

## 1. Prioridade por superfície

| Superfície | Prioridade |
|---|---|
| Desktop / notebook | **Primária** — operação diária |
| Tablet | Boa leitura da Central + listas; edição possível |
| Mobile | **Consulta + ações urgentes** (ver atenção, confirmar? se seguro), não cadastro pesado de variantes |

Não copiar layout desktop encolhido. **Re-priorizar**.

---

## 2. Breakpoints conceituais

| Nome | Largura | Comportamento |
|---|---|---|
| mobile | < 768 | Nav bottom ou drawer; Central empilhada; tabelas → cards |
| tablet | 768–1024 | Sidebar colapsável; drawer full height |
| desktop | > 1024 | Shell completo |
| wide | > 1440 | Limitar measure da Central; não esticar tabela ao infinito |

---

## 3. Central no mobile

Ordem: Requer atenção → Hoje → Próximos dias → resto.  
Visão geral colapsada.

---

## 4. Venda no mobile

Possível rascunho simples; variantes complexas e import = desktop-first messaging (“Melhor no computador”).

---

## 5. Justificativa

Dono olha o celular para **saber o que pegou fogo**; opera de verdade no notebook. Design respeita isso sem fingir que mobile = ERP completo.
