# Hierarquia Visual

---

## 1. Ordem de leitura desejada

1. O que fazer (atenção / CTA)  
2. O que aconteceu (pulso / status)  
3. Contexto (meta, origem)  
4. Números de apoio  

---

## 2. Ferramentas

| Ferramenta | Uso |
|---|---|
| Tamanho / peso | Títulos e métricas (Geist) |
| Cor primary | Um CTA — sólido, nunca degradê |
| Espaço | Separar blocos (ritmo da logo) |
| Mute | Meta e origem |
| Posição | Primário top-right / sticky mobile bottom |
| Mark (3 barras) | Loading / empty / chrome — não competir com conteúdo |

---

## 3. Competição visual proibida

Dois CTAs primary · badge vermelho em 10 rows · ícones coloridos por coluna · gráfico + 6 KPIs acima da atenção.

---

## 4. Central vs Lista

Central: tipografia e respiro lideram.  
Lista: densidade e scan lideram.
