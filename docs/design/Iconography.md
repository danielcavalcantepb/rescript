# Iconography

> Traço alinhado à logo (fina, linear, precisa).

---

## 1. Estilo

- Biblioteca: **Lucide**
- Stroke **1.5** (coerente com hairline da logo)
- Cantos levemente arredondados
- Grid 24px (UI) / 16px (inline)
- Metáfora literal

---

## 2. Uso

| Contexto | Regra |
|---|---|
| Nav | Ícone + label |
| Botão | Ícone opcional à esquerda |
| Status | Badge texto primeiro |
| Empty | Preferir **RescriptMark** muted a ícone genérico |
| Loading | **BrandLoader** (3 barras), não spinner redondo |

---

## 3. Proibido

- Ícones 3D / filled coloridos por módulo  
- Emoji como ícone de sistema  
- Estrelinhas “mágicas” para insights  
- Transformar o mark de 3 barras em ícone de menu  

---

## 4. Justificativa

Texto primeiro; ícone como âncora. O símbolo exclusivo da marca é o “E” de três linhas — não Lucide.
