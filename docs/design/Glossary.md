# Glossário de Design

| Termo | Significado |
|---|---|
| **Brand Identity** | Fonte da verdade visual (`BrandIdentity.md`) — nasce da logo oficial |
| **RescriptMark** | Símbolo exclusivo: três barras do “E” |
| **BrandLoader** | Loading com opacity stagger nas três barras |
| **Quiet Instrument** | Direção visual: precisão calma |
| **Central de Decisão** | Home; não dashboard |
| **Insight Card** | Card de conclusão acionável |
| **Metric Card** | Número com contexto; subordinado |
| **Command Palette** | Busca+ações global ⌘K |
| **Comfortable / Compact** | Densidades por contexto de tela |
| **Primary action** | Único CTA forte da vista |
| **Progressive disclosure** | Avançado sob demanda |
| **Curadoria** | Teto de itens de atenção |
| **Domínio vence** | Regra de conflito UX vs negócio |
| **Disponível** | Físico − reservado (mostrar por padrão) |
| **Confirmar venda** | Verbo oficial (não “concluir”) |
| **Empty útil** | Empty que ensina o próximo passo |
| **Anti-ERP** | Recusar padrões densos de legado |
