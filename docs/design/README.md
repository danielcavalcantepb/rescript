# Rescript — Design de Produto

> Especificação da experiência e da **identidade visual oficial**.  
> Fonte da marca: logo oficial → [`BrandIdentity.md`](./BrandIdentity.md).

---

## 1. Tese de design

> O Rescript não vende telas. Vende **clareza**.

O concorrente não é outro ERP. O concorrente é a **complexidade**.

## 2. Precedência

1. FounderDecisions e domínio aprovado  
2. ADRs / invariantes / BusinessRules  
3. Estratégia (`DecisionCenter`, `Positioning`, `IntelligencePrinciples`)  
4. **`BrandIdentity.md`** (marca visual oficial)  
5. Demais docs de design  

**Se UX conflitar com domínio → domínio vence.**  
**Se token/visual conflitar com Brand Identity → Brand Identity vence.**

## 3. Referências de qualidade

**Sim:** Linear · Stripe Dashboard · Notion · Vercel · Arc · Apple HIG · GitHub · Raycast  

**Não:** Bling · Tiny · Omie · Conta Azul · SAP · Totvs — e qualquer padrão de “ERP brasileiro denso”.
