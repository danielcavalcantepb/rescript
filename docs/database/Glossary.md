# Glossário — Modelo Lógico

| Termo | Significado |
|---|---|
| **FT** | Fonte de verdade |
| **DER** | Derivado / materializado reconstruível |
| **Agregado** | Fronteira de consistência DDD |
| **Ownership** | organization_id dono do dado |
| **FnOnly** | Escrita só via operação transacional |
| **Ledger** | Append-only de movimentos |
| **Reservation** | Compromisso ≠ movement |
| **Snapshot** | Cópia imutável na Sale |
| **Outbox** | Eventos na mesma TX do fato |
| **IdempotencyRecord** | Replay seguro de ops |
| **combination_hash** | Identidade da combinação de atributos |
| **available** | physical − reserved |
| **FinancialEntry** | Nome genérico FUT de caixa; MVP usa Payment |
| **C-TENANT** | Consistência de organização no grafo |
| **OQ / FQ / WT** | Open Question / Founder Question walkthrough / Walkthrough issue |
| **Quiet Instrument** | Direção de design (não afeta schema) |
