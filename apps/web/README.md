# Rescript Web (`apps/web`)

TanStack Start app — Sprint 0 / Fase 1 (UI navegável com mocks).

## Scripts

```bash
# na raiz do monorepo
npm install
npm run dev

# ou dentro de apps/web
npm run dev
npm run build
npm run generate-routes
```

Abra http://localhost:3000 — use **Entrar** (auth mock).

## Escopo desta fase

- Layout Quiet Instrument
- Central de Decisão, Clientes, Produtos, Vendas
- Command Palette (⌘K)
- Dados mockados consistentes
- Sem Supabase, RLS, regras de negócio reais
